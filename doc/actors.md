# Действующие лица

Справочник элементов модели. Блоки здесь только объявляют имена и типы, поэтому
отдельной схемы у этого файла нет.

## Люди и агенты

Автор пишет документацию и модель, а на схемах вручную правит раскладку.

```model
author "Автор документации" [person]
```

ИИ-агент читает документацию и может править модель, а формат узнаёт из карточки.

```model
ai-agent "ИИ-агент" [person]
```

## Приложения

archtale читает документацию, проверяет модель и генерирует схемы.

```model
archtale "archtale" [archtale]
```

draw.io desktop рендерит картинку схемы. В нём же автор правит схемы и фигуры типов.

```model
drawio "draw.io desktop" [application]
```

## Файлы

Markdown-документация хранит прозу, блоки `model` и теги схем.

```model
markdown "Markdown-документация" [file]
```

Файл схемы `.drawio.svg` — это картинка для документации и одновременно исходник
для draw.io, в котором хранится ручная раскладка.

```model
diagram-svg "Файл схемы" [file]
```

Файл типа в `archtale-types/` задаёт фигуру для всех элементов своего типа.

```model
type-svg "Файл типа" [file]
```

Карточка `ARCHTALE.md` кратко описывает формат для людей и ИИ-агентов.

```model
card "Карточка ARCHTALE.md" [file]
```
